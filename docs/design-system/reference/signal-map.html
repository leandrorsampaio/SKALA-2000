· Rules that apply to every row

One LampWindow size (96×46). Unknown enum values light the OTHER window of their group where one exists, never leave a wrong window lit. Every reading carries a time-to-live: a source that stops reporting darkens its instruments and raises DATA STALE. A missing or renamed field costs one instrument, never the console. Join keys and the auth token are never displayed. Numbers on nixies are fixed width with leading zeros and show all nines on overflow. Drum counters only move forward and are persisted by the app.
