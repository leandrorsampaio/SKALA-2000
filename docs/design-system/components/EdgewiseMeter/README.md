A narrow 70×220 vertical profile meter: a straight scale with a red pointer riding beside it and a red sector from 0 to 20. The console uses exactly one, for battery charge on panel D, next to the ON MAINS / ON BATTERY / CHARGING / BATTERY LOW windows.

The pointer slides to a new value in 500 ms with a small overshoot. Below 20% the BATTERY LOW window goes to `flash` and joins the alarm logic (buzzer until acknowledged).

**Consumer provides:** label, value 0 to 1.

**Native.** Same dial-once, pointer-only animation as MovingCoilMeter; translate the pointer along y from 204 (0%) to 16 (100%).

**Depth.** Same raised bakelite housing and dial-behind-glass treatment as MovingCoilMeter.
