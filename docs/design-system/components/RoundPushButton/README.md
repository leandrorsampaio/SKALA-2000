A round black bakelite pushbutton, domed and glossy, sunk in a polished chrome collar, with two separate LampLens indicators above it: green ON and white OFF. This is the control of panel D (computer controls): SLEEP MODE, TURN OFF MONITOR, FC1, FC2.

The cap itself never lights. Press and release work as in PushButton: the dome sinks into the collar (89% scale, hole shadow across its top), two clicks. On release **both lenses go dark**, the command is sent, and when the Mac reports the new state the matching lens lights with a relay `clunk`. If nothing comes back in 3 s both stay dark: that is the fault indication, and the instruction plate on panel D says so.

**Consumer provides:** cap text, plate label, current state, the toggle command, the state signal.
