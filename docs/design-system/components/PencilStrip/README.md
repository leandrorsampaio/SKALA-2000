A 96×46 paper strip in a thin aluminium card holder under each session number on panel A where the operator writes the project name by hand. It is the only free text on the console: the hardware has no way to show strings.

An editable text field: `pencil` style (Caveat 22px, graphite #4a4a48), centred, 12 characters at most, no placeholder, no border change on focus other than the standard amber focus ring. Stored per session slot, persists across launches. The app may pre-fill it with the basename of the session's working directory when a session first appears in an empty slot; after that it belongs to the operator.

**Depth.** The strip is an overlay on the metal, not a hole in it: a 4px aluminium holder frame screwed onto the paint (bright top and left edges, grey bottom and right, `plate-raise` shadow onto the panel), with the paper card slid inside it, a hair below the frame so the frame shades the card's top edge.
